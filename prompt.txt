# PROJECT: AUTODEPLOY
## Automated CI/CD Pipeline with GitHub Actions, Docker & Render

### 1. ROLE AND OBJECTIVE

Act as a Senior DevOps Engineer and Full-Stack Developer.

Your task is to design and implement a beginner-friendly but professionally structured CI/CD project called **AutoDeploy**.

Build a minimal web application and implement a complete automated CI/CD pipeline that demonstrates how modern software teams automate testing, containerization, and application deployment.

This project must be:
- Fully functional.
- Easy to understand and maintain.
- Professionally structured.
- Suitable for demonstrating in technical interviews.
- Implementable within approximately 2 hours.
- Free or based on free-tier services wherever possible.

IMPORTANT: Prioritize a working implementation over unnecessary features.

Create a production-appropriate Dockerfile.

Requirements:

### 6. GITHUB ACTIONS CI/CD PIPELINE

This is the MOST IMPORTANT component.

Create:

.github/workflows/ci-cd.yml

Implement an automated workflow with the following stages.

**STAGE 1: TRIGGER**

Trigger the workflow when:
- Code is pushed to the main branch.
- A pull request is created targeting main.

**STAGE 2: CHECKOUT**

- Use the official GitHub checkout action.
- Download the latest repository code.

**STAGE 3: PYTHON ENVIRONMENT**

- Set up a compatible Python version.
- Install project dependencies.
- Install Pytest.

**STAGE 4: AUTOMATED TESTING**

- Execute pytest.
- Display test results.
- Stop the workflow if any test fails.

**STAGE 5: DOCKER BUILD**

For successful pushes to main:
- Build the Docker image.
- Tag the image appropriately.
- Validate that the Docker image builds successfully.

**STAGE 6: DEPLOYMENT**

Configure deployment to Render.

Requirements:
- Deploy only after successful testing.
- Deploy from the main branch.
- Use secure GitHub repository secrets.
- Never hardcode deployment credentials.
- Ensure pull requests do not trigger production deployments.

Choose the simplest reliable deployment strategy.

Prefer Render's GitHub integration with automatic deployment after successful CI checks. If using a deployment hook, configure it securely through GitHub Actions secrets.

IMPORTANT:
Explain the difference between CI and CD in the implementation.

Do not claim that Docker images are published to a registry unless an actual registry push is configured.
